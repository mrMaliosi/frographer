# Telegram-бот Стенографист

Telegram-бот, разработанный для работы в качестве стенографиста чата. Он записывает беседы, предоставляет краткие сводки (саммари), повторяет сообщения конкретных пользователей и анализирует личности участников.

## Возможности

- **Логирование чата**: Автоматически записывает сообщения в локальную базу данных SQLite.
- **Суммаризация**: Предоставляет краткую сводку истории чата за день с помощью LLM (интегрировано с Ollama).
- **Зеркалирование**: Может быть настроен на повторение каждого сообщения, отправленного определенным пользователем в чате.
- **Профилирование**: Анализирует историю сообщений пользователя для создания характеристики его личности.

## Установка

1. **Клонируйте репозиторий** (или скопируйте файлы).
2. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```
3. **Настройка прав бота (ВАЖНО)**:
   Чтобы бот мог записывать все сообщения в чате, а не только команды, нужно **выключить Privacy Mode**:
   - Напишите **@BotFather**.
   - Отправьте команду `/mybots`.
   - Выберите вашего бота $\rightarrow$ **Bot Settings** $\rightarrow$ **Group Privacy** $\rightarrow$ **Turn off**.
   - После этого удалите бота из группы и добавьте его снова.
4. **Настройка окружения**:
   Создайте файл `.env` в корневом каталоге со следующим содержимым:
   ```env
   BOT_TOKEN=ваш_токен_телеграм_бота
   LLM_API_KEY=ваш_ключ_api_llm
   OLLAMA_BASE_URL=http://localhost:11434
   OLLAMA_MODEL=llama3
   OLLAMA_API_KEY=ваш_ключ_если_есть
   ```

### Как получить токен бота

Чтобы получить `BOT_TOKEN`, выполните следующие шаги:
1. Найдите в Telegram пользователя **@BotFather** (официальный бот для создания других ботов).
2. Отправьте ему команду `/newbot`.
3. Следуйте инструкциям:
   - Придумайте **имя** бота (например, `МойСтенографБот`).
   - Придумайте **username** бота (он должен быть уникальным и заканчиваться на `_bot`, например, `my_steno_bot`).
4. После успешного создания BotFather пришлет вам сообщение с API-токеном. Скопируйте его и вставьте в файл `.env` в поле `BOT_TOKEN`.

## Запуск бота

```bash
python3 -m bot.main
```

## Команды

- `/start` — Показать справку и доступные команды.
- `/set_target [@ник]` — Установить цель для повторения. Можно использовать **ответ (reply)** на сообщение или указать @никнейм.
- `/summarize [дата или дата...дата]` — Получить сводку. По умолчанию за сегодня. Можно указать дату (`YYYY-MM-DD`) или диапазон (`YYYY-MM-DD...YYYY-MM-DD`).
- `/profile [@ник]` — Получить характеристику личности. Можно использовать **ответ (reply)** на сообщение или указать @никнейм.
- `/stats` — Показать статистику чата: общее кол-во сообщений, топ-10 авторов и топ-20 часто используемых слов.
- `/holy_yandex` — Сгенерировать хвалебный факт о Яндексе.
- `/bad_yandex` — Сгенерировать ироничную жалобу на Яндекс.

## Технические детали

- **Язык**: Python 3.10+
- **Фреймворк**: `aiogram`
- **База данных**: `SQLite`
- **Суммаризация**: Используется Ollama. Для работы необходимо, чтобы сервер Ollama был запущен и доступен по адресу, указанному в `OLLAMA_BASE_URL`.

### Настройка Ollama

1. **Локально**: Установите Ollama с [ollama.com](https://ollama.com) и запустите нужную модель (например, `ollama run llama3`).
2. **В Облаке**: Если Ollama развернута на удаленном сервере (VPS), укажите его IP-адрес в `OLLAMA_BASE_URL` (например, `http://123.123.123.123:11434`).
3. **Модель**: Убедитесь, что модель, указанная в `OLLAMA_MODEL`, загружена на сервере.
